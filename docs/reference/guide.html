Before you start

Back up the entire SD card outside the card itself and retain your original official v3.26 HEX file for rollback. Open the patcher on HTTPS or localhost in a modern browser. Firmware delivery uses downloads and manual file-manager copying; no browser SD-card access is required. Firmware and patterns stay on your computer; nothing is uploaded.

Choose, verify, download and copy

  1. Open the firmware tool and leave v0.9.0 selected for the confirmed baseline. Select v0.10.0-alpha.1 only for deliberate CC testing on a backed-up card.
  2. Choose the original official Ground Control v3.26 HEX. The tool verifies its contents; unknown or already-patched images cannot be built.
  3. Click Build firmware. The tool applies the pinned bundle, re-parses the output and shows checksums under diagnostics.
  4. Click Download .hex to save the result to your computer. The short filename is GCV326B0.HEX for preview 0.9.0 or GCV326C1.HEX for alpha 0.10.0-alpha.1.
  5. Hold PROJ for about five seconds on the module to enter USB storage. Open the card in Finder, File Explorer, or your operating system’s file manager.
  6. Copy the downloaded HEX to the card root, outside the project folders. Keep only one firmware HEX there. Preserve the short filename; remove any duplicate-download suffix such as “(1)”.
  7. Wait for copying to finish and safely eject the volume using your operating system. Follow the module’s update procedure and keep power stable throughout updating.

The patcher does not connect to or write to SD cards. Browser firmware writing was removed because of FAT32 and long-filename issues. Transfer the file manually; the module’s bootloader performs the update.

What is included

The baseline adds eight-note MIDI chords on tracks 1–3, per-note velocity, live recording and step editing, embedded single-file pattern storage, ownership-aware switching, locked handoff and quiet startup restore. CV/gate outputs remain monophonic and the drum format stays native.

The separate CC candidate adds four step-quantized controller lanes per melodic track, incoming MIDI CC recording and external CV-to-CC recording. It has emulator coverage but still needs physical timing, input mapping and power-cycle tests. See features and release notes.

Return to stock or the baseline

Keep your off-card backup. Place only the original official HEX, or the retained v0.9.0 HEX, at the card root and follow the normal module update procedure. Stock firmware plays native mono notes and removes embedded data when it rewrites patterns. The baseline does not record or play CC automation and removes it when saving. Use notes-only export when downgrading.

If something fails

Stop testing and retain the affected files. Report the selected release, browser, actions, verification message and whether the issue occurred on hardware. Share a minimal pattern only if it contains no private material. Use the repository issue tracker, not Endorphin.es support.
