Polyphony v1 — quick install v3.26 + p1

andrewdesena.github.io/ground-control-patcher · unofficial
  1. Back up the microSD card. Copy the whole card somewhere safe first.
  2. Get the stock firmware. Download the official gc-*.hex (v3.26) from endorphin.es.
  3. Build in the browser. Open the patcher (Chrome/Edge, https), select the .hex, tick Polyphony v1, click Build. Confirm ✓ v3.26.
  4. Mount the card. Hold PROJ ~5 s on the module. In the tool: Connect GC SD card → pick it → Install to GC.
  5. One file, root, marked name. The patched gc-*.hex goes to the card ROOT as <stock>-poly1.hex, and must be the only firmware .hex there.
  6. Flash. Press PROJ ~5 s again — the module reboots and flashes. Power-cycle when done.
The patcher makes a file; it does not flash the module. The module's bootloader flashes a gc-*.hex at the card root. Keep the v2.x SD-recovery method handy for the first modded image.
