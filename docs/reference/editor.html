Open, edit, save

  1. Open the pattern editor. Connect the SD card root, or import a native pattern or editor project JSON.
  2. Choose the exact project, track and letter in the browser. Missing letters do not fall back to pattern A.
  3. Edit notes and settings. Changes stay in browser memory until saved/exported. Browser recovery is a convenience, not a complete backup.
  4. Use Save changes for the connected card, Export pattern file for a module-ready file, or Export editor project for a workspace backup. The module does not load editor project JSON.

Card writes preserve the previous file as a byte-for-byte .bak and verify the replacement. A backup or write failure stops saving. Keep a separate off-card backup too. Native patterns contain binary trailers: do not edit them as plain JSON. Old poly<letter> sidecars are ignored and never created or migrated.

Drag velocity bars to set values. Shift-drag adjusts selected notes relatively. Use the inspector for exact values. A whole gesture is one undo step. Out-of-range edits and collisions are rejected rather than silently dropping notes.

Step timing and preview

Patterns have 1–128 steps and up to eight notes per step. Tie, slide and ratchet apply to the whole selected step or steps. Notes do not have independent durations. Use zoom and fit controls to navigate. Click the ruler to set an insertion/loop start; Shift-click sets a loop end.

Browser preview is a simple audition instrument, not a complete hardware simulation. Hardware shuffle, generators, modulation, MIDI routing and CV outputs are not reproduced.

CC lanes and external CV

Requires the experimental v0.10.0-alpha.1 firmware. Add a controller lane, choose its number and draw or numerically edit values. Values are quantized to steps. An absent point sends nothing; zero is a real event. Right-click removes a point. Four lanes are available on each melodic track; drums do not use this extension.

Choose MIDI / editor to draw automation or record incoming MIDI CCs. To record external CV, choose input 1–4 as the lane source and set the CC minimum/maximum; reversing the range inverts the mapping. The track/pattern being edited is the destination.

Save the pattern, load it on the candidate firmware, start playback and enable native live recording. MIDI messages follow the configured receive channels; CV is sampled at step boundaries. Disarm to stop recording. Save on the module before leaving the letter, then reopen its pattern file in the editor to edit the recorded values.

Candidate status and downgrade limits are documented in CC implementation and hardware acceptance. Do not treat external CV voltage scaling or input order as hardware-verified yet.

Recovery and help

Use the browser draft recovery button after an interrupted session, then export a project backup. If a card file changed externally after opening it, saving stops: reopen the file and reconcile the changes. Get support through this repository’s issue tracker, not the manufacturer.
