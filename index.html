    Compatibility and local processing

    Only the verified stock v3.26 image is supported. Already-patched and unknown firmware files are rejected. Building requires a browser with SHA-256 support, available on HTTPS or localhost. You supply the vendor firmware; this tool contains patch definitions only.

    Build polyphonic firmware

    The release includes the tested polyphony, recording, pattern switching, and startup changes as one bundle.

    Build diagnostics and checksums 
    Choose a stock firmware file to begin.
    3

    Save the firmware

    Hold PROJ for about five seconds to enter USB storage. Choose the card root, then write the firmware. You can also download it and copy it yourself.

    Card filename: GCV326B0.HEX. Direct writes use this short name automatically. If copying a download manually, rename it to this name first.

    File written and verified. Finish on the module.

    Make sure only this firmware HEX is at the card root. Safely disconnect USB storage, then follow the module’s update procedure. A verified file write confirms the card contents; the module performs the firmware update.

    Before installing

      Release notes

      Preview 0.9.0 includes live polyphonic recording, locked pattern switching and quiet startup restore. Public versions remain below 1.0 until the complete experience passes hardware acceptance. Melodic patterns store chord data inside each pattern file. The drum track retains its native format.

      Return to stock

      1. Keep a backup of your original stock v3.26 firmware and SD card.
      2. Place only the original stock HEX file at the card root and use the module’s normal firmware update procedure.
      3. Stock firmware plays the native mono notes. Saving a pattern from stock firmware removes its embedded chord data, so retain your backup.
